# Research

Answers to the questions in QUESTIONS.md go here, one file per question: `Rxx-short-title.md`.

Each answer file must contain:
1. **Answer**: short and direct.
2. **Evidence**: links to official docs (Microsoft Learn, fema.gov, federalregister.gov, ecfr.gov, irs.gov, dol.gov, fns.usda.gov, census.gov), with the date checked.
3. **Impact on the build**: which doc sections, data files, or tasks change.
4. **Code snippet or config**, if relevant (install command, minimal example).

After writing an answer, update the VERIFY markers it resolves in the docs it names.

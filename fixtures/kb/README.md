# Curated knowledge-base files

Create one Markdown file per official source page. Keep a faithful, shortened
summary of that page in plain language; do not scrape or add advice that the
source does not give. Add a Spanish file when an official Spanish page exists.

```markdown
---
url: https://www.fema.gov/assistance/individual/after-applying/appeals
title: Disagreeing with FEMA's decision
agency: FEMA
lang: en
topic: appeals
fetched_at: 2026-09-23
---
## How long do I have to appeal?
Summarize the page here.
```

The same files power mock search and the Azure AI Search index. Verify every
fact against its `url` and keep one file per URL.
